Moxie REPL

Type an expression and see its value and type; it is kept as res1, res2, ... and it is the latest. Declarations (fn, tuple, x = 5) join the session. A line ending in : continues until a blank line. Try :help. It runs in your browser using the reference interpreter, so nothing is sent anywhere.
