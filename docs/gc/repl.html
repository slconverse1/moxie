moxie/gc REPL

Type an expression and see its value and type: the results are kept in $res1, $res2, ..., where $res1 is the most recent result, $res2 the result before it, and so on. A result can be used in an expression, as in $res1 + 5. Declarations (fn, tuple, x = 5) join the session. A line ending in : continues until a blank line. Try :help. It runs in your browser using the reference interpreter, so downloading it is avoided.

1 + 2 (Enter to run, arrow UP for earlier inputs; scroll UP/DOWN to navigate the REPL box)
