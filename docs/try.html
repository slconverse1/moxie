Try moxie

Pick a sample or write your own, then run it. Tick "moxie/gc rules" to run it under the garbage-collected language (collections grow as needed). The program runs in your browser using the reference interpreter, so nothing is sent anywhere. A program is one file, and its top level is main. The page is a sandbox: there is no network and no native libraries, signals is not available, and files live in memory only. A program that needs one of those is refused when it is checked, with a message that says so. Run moxie --platform=browser check FILE to see the same answer on your own computer.
